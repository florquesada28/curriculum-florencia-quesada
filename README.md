Este trabajo práctico consiste en el desarrollo de un portfolio web personal maquetado bajo HTML5 y diseño CSS, tomando como base un prototipo de Figma. El sitio cuenta con una página de inicio, una sección de proyectos y un formulario de contacto interactivo, utilizando un sistema unificado de navegación y una paleta principalmente de tres colores, rojo #FF0000, marrón #19150A y un verde menta #59CA90
Se usó la tipografía Archivo en sus distintos pesos (como Thin Italic para subtítulos y Semibold para los títulos principales)
Editor de código: Visual Studio Code
Tamaño de pantalla: 1920 x 1080
